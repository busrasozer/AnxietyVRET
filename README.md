# AnxietyVRET

AnxietyVRET is an event-centered OWL 2 DL ontology for the semantic integration of clinical scale data (GAD-7), physiological signals (heart rate) and in-session virtual reality event logs in Virtual Reality Exposure Therapy (VRET). A SWRL rule layer infers high physiological arousal and GAD-7 symptom-severity classes, and 29 competency questions (CQs) are answered with SPARQL.

This repository accompanies the MSc thesis *Yaygın Anksiyete Bozukluğu İçin VR Destekli Maruz Bırakma Programı: Faz Tabanlı Tasarım ve Veri Odaklı Değerlendirme* (Sakarya University, 2026) and the manuscript *ANXIETYVRET: An Event-Centered Ontology for Semantic Integration and Safety Monitoring in Virtual Reality Exposure Therapy for Generalized Anxiety Disorder*.

> **Scope.** All data in this repository are synthetic. The ontology is a model-design and proof-of-concept artifact; it has not been validated with real patient data and does not establish clinical validity, real-time performance or therapeutic efficacy.

## Rule layer

| Rule | Condition | Inference |
|---|---|---|
| 1 | `heartRateValue` ≥ `baselineHeartRate` × 1.2 | `HighPhysiologicalArousal` |
| 2 | `heartRateValue` ≥ `safetyUpperHRLimit` | `HighPhysiologicalArousal` |
| 3 | `gad7TotalScore` ≤ 4 | `MinimalAnxiety` |
| 4 | 5 ≤ `gad7TotalScore` ≤ 9 | `MildAnxiety` |
| 5 | 10 ≤ `gad7TotalScore` ≤ 14 | `ModerateAnxiety` |
| 6 | `gad7TotalScore` ≥ 15 | `SevereAnxiety` |

The inferred classes are **not asserted** in the ABox; they appear only after the reasoner is run. `Safety_Event` individuals are **asserted** in the ABox (they are not generated by a rule) and are traced to their interventions by the CQ28 query. The GAD-7 classes are symptom-severity labels, not clinical diagnoses.

## How to reproduce the validation

1. Open `AnxietyVRET_v21_1_abox.ttl` in Protégé (5.6.x) and add `AnxietyVRET_v21_1.owl` as an imported ontology (Active ontology → Imported ontologies → import from local file). Optionally add `boundary_tests_abox.ttl` the same way.
2. Reasoner → Pellet → Start reasoner. The knowledge base should be consistent.
3. File → Export inferred axioms as ontology (include class assertions), then open the exported ontology.
4. Run the queries in `cq_queries.rq` in the SPARQL Query tab and compare with the expected results given above each query.
